# 🐘 PostgreSQL (psql) — Database Assignment 🚀

## 📘 Overview
This assignment focuses on mastering **PostgreSQL (psql)** — one of the most powerful open-source relational database systems.  
The tasks explore **DDL (Data Definition Language)**, **DML (Data Manipulation Language)**, **aggregate functions**, **clauses**, and **core SQL operations**.  

By completing this, you’ll learn how to **create, query, and manipulate** data efficiently in a PostgreSQL environment.
